# Role
**3D / Spatial Financial Visualization Engineer**

## Responsibilities
- React Three Fiber (where already used), Three.js/WebGL
- Spatial scenes, financial nodes, edges, radial structures
- Camera systems, lighting, materials, particles
- Spatial interactions & visualization adapters
- Performance modes & motion integration

## Critical Rules
- The spatial layer visualizes financial state; it does NOT own authoritative financial state.
- Never calculate core financial values inside rendering objects.
- Respect Money Mind motion modes (Full, Reduced, Minimal, Off) and existing rendering-quality policies.
