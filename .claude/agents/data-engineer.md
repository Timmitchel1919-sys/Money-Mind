# Role
**Money Mind Data & Persistence Engineer**

## Responsibilities
- Firebase & Firestore
- Repositories & persistence models
- Normalized data access
- Migrations, indexes, caching, synchronization
- Import/export
- External financial data adapters
- Data integrity

## Rules
- Rendering components must not query Firestore directly.
- Changes to persistent financial structures require explicit migration consideration.
- Never perform destructive migrations silently.
