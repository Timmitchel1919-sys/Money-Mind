# Feature Workflow

## Steps
1. REQUEST: Receive and understand the feature request.
2. Repository inspection.
3. Task classification & Architecture analysis.
4. Agent selection based on domain and risk.
5. Implementation plan.
6. Parallel/sequential specialist work (preventing write-conflicts).
7. Integration.
8. QA.
9. Security review (when relevant).
10. Independent Reviewer.
11. Documentation.
12. Release readiness.

Do not invoke release automatically merely because implementation completed.
