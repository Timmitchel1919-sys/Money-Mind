# ADR 0004: Progressive enhancement

- Status: Accepted
- Date: 2026-08-21

## Decision

Critical financial workflows must remain available without WebGL. The experience respects full, reduced, minimal, and off motion preferences and adapts to coarse pointers and limited devices.

## Consequences

Spatial views require accessible non-spatial equivalents. Capability detection selects enhancements; it does not block core functionality.
